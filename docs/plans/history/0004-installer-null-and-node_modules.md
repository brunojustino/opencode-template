Status: done (closed out 2026-09-12; archived to history/)

"You cannot call a method on a null-valued expression" right after the header line.
Spec: approved in session

## Diagnosis

- The template repo acquired `.opencode/node_modules/` (+ package.json, package-lock.json)
  from skills-CLI/opencode tooling after the previous scratch-test runs.
- The target project also has `.opencode/node_modules/` (skills-CLI runtime) containing
  empty files at identical paths (e.g. `node_modules/pure-rand/lib/types/RandomGenerator.js`,
  size 0).
- `Copy-TemplateTree -RelPath ".opencode" -Mode "Update"` walked the source node_modules,
  found the colliding dst file, and `Get-Content -Raw` returned `$null` for the empty file
  (PS 5.1) -> `$dstText.Trim()` -> null-method crash.
- Secondary bug: even without the crash, Update mode would overwrite the target's entire
  `.opencode/node_modules` with the template's copies. Dependency dirs must never be copied.
